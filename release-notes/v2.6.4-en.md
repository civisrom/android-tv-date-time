# Version 2.6.4

**The Android app operates in test mode.**

This release combines the change descriptions from 2.6.2, 2.6.3 and 2.6.4. Version sections preserve the history: later changes clarify the current application behavior. Shared download and license information appears once.

## In this rebuild

- Added a Russian and English “Terms of use” section at the bottom of the Android main screen: the program is provided “as is”, without warranties to the extent permitted by law, and is used at the user's own risk. The section can be reached with a remote control.
- In desktop menu item 10 help, each explanation now appears in the terminal's normal text color, followed by its command in green. Examples are separated by blank lines. Updated both Russian and English layouts.

## Changes in 2.6.4

- Corrected and expanded the desktop versions' built-in ADB help in Russian and English: explained commands, connection steps, screenshot/report saving and terminal limitations. Fixed connection error reporting and ADB output encoding on Windows.
- Added guided TV setup, favorite devices and NTP servers, device checks on reconnect, and remote-accessible address copy/paste controls. Favorite devices now follow automatically discovered devices.
- Fixed keyboard handling, focus and large-text label clipping in the APK, full-address NTP search and stale information after switching devices. Fixed wireless pairing and Android 17 display-mode parsing.
- Improved NTP checks and clock comparison. Added system-default time-source reset, undo for the last change and before/after information. Saving a setting no longer implies confirmed synchronization; network operations have deadlines.
- Fixed shared ADB use across desktop windows, external program launches from packaged builds, closed-input exit and Russian input/output on Windows. Improved settings persistence; pairing codes are kept out of process arguments and redacted from errors.
- Added `0.openwrt.pool.ntp.org`. Updated vulnerable build dependencies, locked versions and checksums, and expanded automated checks. Updated the Russian and English guides for the new features.

Checks cover Windows, Linux, macOS and emulators running Android 6–17, Android TV and Google TV. Individual TV and set-top box firmware still requires testing on the device itself.

## Changes in 2.6.3

- Added time zone changes on Android with a collapsible menu, result verification and attempted recovery on failure. NTP settings stay unchanged; operation was confirmed on NVIDIA SHIELD running Android 11.
- Improved Android and desktop NTP selection with five spaced requests, reply validation, availability checks and delay stability assessment. Added seven verified alternative addresses.
- Strengthened address and time-server validation with clear rejection reasons. Large clock differences do not block applying NTP; clock checks show local time, the time zone and UTC.
- Desktop automatic setup now discovers devices via mDNS first: press Enter to confirm a found address. Removed the experimental label; first-time code pairing remains a separate step.
- Fixed Android interface flickering during background connection checks. Added long-press copying of text and addresses with ports.
- Improved country code/name search, scrolling and keyboard handling. Starting a scan collapses lists; selecting a result clears the results and highlights the address field three times.
- Grouped functions into gray panels, emphasized status text and gave primary and secondary buttons different fills. Pairing is collapsible; connection and USB guidance has been expanded.
- Expanded device details with firmware, chip, graphics, storage, display/HDR, audio, decoder declarations and network data. The list starts collapsed and hides unavailable details. Fixed reading compatibility with Android 6.
- Expanded technical details in diagnostics and copied reports. Added a project source code label and GitHub link to Android and desktop versions.
- Updated the Russian and English guides and expanded automated checks on Android 6, 11 and 16.

If your phone cannot discover the TV over USB, try the desktop version. Available information and commands depend on the device firmware.

## Changes in 2.6.2 — USB, time verification and interface improvements

**Historical note from the 2.6.2 description:** prerelease; the Android app operates in test mode.

**Notice for the September 7, 2026 rebuild of 2.6.2: the APK signing certificate changed.**
If you installed an earlier APK, uninstall it before installing this build.
An in-place update from the old signature is not supported; local settings
and ADB authorizations need to be configured again. The version remains 2.6.2.

**Validation update:** six-digit code pairing in the newer Wireless debugging
mode has been tested by a user on a real device and confirmed to work.

Changes since 2.6.1: ADB over USB, clearer device connection steps, local
diagnostics and Android usability improvements.

### Added

- **Android time setup verification.** After saving an NTP server, the app
  compares the connected device's clock with a fresh response from that server.
  It shows the difference, measurement uncertainty and automatic-time setting,
  with a separate button to repeat the check. Agreement at the time of the
  measurement does not verify Android's synchronization source or time zone.
- **ADB over USB on Android, Windows, Linux and macOS.** Select a connected
  TV, set-top box, phone or tablet to configure NTP and read device information
  without entering an IP address. Wireless connection methods remain available.
- **Visible application version** in the Android app and the desktop main
  menu; `--version` is also available on the command line.
- **Android diagnostics through a separate button.** The log records results
  of USB, network connection and NTP operations. It supports copying and
  clearing with confirmation. The latest 200 events are retained for up to
  7 days, only on the device, with no automatic upload. ADB keys, passwords
  and pairing codes are not logged.
- **Clearer network discovery.** Discovered devices have a green
  “Device found” label with their name and address. Device discovery and a
  successful connection are shown as separate states.
- The pairing section explains that the code is used for the newer
  Android 11+ wireless debugging mode when the controlled device's firmware
  offers that feature.

### Fixed and improved

- Disabled Gradle configuration caching and GitHub Actions caching for the
  release signing job. The private key and passwords are supplied only to the
  signing step and are not included in published application files.
- Android network discovery now appears directly below the device connection
  section. In device information, the time server follows the Android version;
  both its label and value are highlighted in green.
- The desktop USB menu explicitly asks you to enter a device number and
  press Enter. Once the connection is verified, it displays the connected
  device's name and the next steps: option 5 for information, options 1 and 2
  for NTP settings.
- The `UNAUTHORIZED` state includes instructions to approve the RSA prompt
  on the target device. A successful connection requires an ADB probe command,
  not just a device appearing in the list.
- Automatic NTP setup uses the selected USB connection.
- Android USB discovery distinguishes no devices, a USB device without an
  ADB interface, and enumeration errors. An empty list is no longer described
  as successful discovery. Diagnostics include device counts and system USB
  state information.
- Completing a long operation no longer overwrites a fresh USB device list
  with stale state. USB attachment, removal and operation cancellation are
  handled.
- The Android main screen always shows the connection IP address, NTP settings
  and Android 11+ pairing form without collapsible menus. A time server can be
  chosen and checked before connecting; applying it requires a connection.
  Additional sections can be collapsed. Input and section state are preserved
  while viewing diagnostics.
- Improved green status contrast, status bar icon visibility on light
  backgrounds, remote-control navigation, large-font layouts and landscape
  display. Buttons remain accessible with the keyboard open on older Android
  versions.
- GitHub Actions check names now show only the OS and Python version.
  Added UI checks on Android 6 and Android 16, plus a Windows build artifact
  for the `dev` branch.

### USB setup and known limitation

Enable USB debugging on the target device, use a data-capable cable and
approve the RSA prompt. A phone running the app must support USB host/OTG;
the target must use a port that supports USB device mode. Windows may require
the manufacturer's ADB driver; Linux may require udev rules.

**A Windows → NVIDIA SHIELD USB connection and reading device information
have been confirmed in user testing. Phone → SHIELD discovery remains under
investigation:** Android returns an empty USB device list on the mobile
devices tested. Version 2.6.2 improves diagnostics and state handling, but a
fix for this specific case has not yet been confirmed.
