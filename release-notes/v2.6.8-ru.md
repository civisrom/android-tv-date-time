## Android TV Time Fixer 2.6.8

**Приложение для Android работает в тестовом режиме.**

- **Обновление из приложения:** в Android-приложении появился раздел «Обновление приложения». Он проверяет новую версию на GitHub, скачивает APK, сверяет размер, контрольную сумму SHA-256 и подпись и передаёт файл системному установщику Android. Установку всегда подтверждает пользователь; при первом обновлении Android попросит разрешить приложению установку приложений. Версию 2.6.8 нужно установить вручную, следующие версии можно будет ставить прямо из приложения.
- **Безопасность:** в версиях для Windows и macOS — Python 3.12.16 с исправлениями `tarfile` и `ssl`, zlib 1.4 и Expat 2.10.0. Обновлены набор корневых сертификатов certifi 2026.10.23 (удалены корневые CA emSign со скомпрометированными промежуточными ключами), pyasn1 0.6.5 (исправлены отказы в обслуживании при разборе ASN.1) и другие библиотеки Python. В Linux-сборку включено свежее исправление безопасности liblzma5 из Ubuntu 22.04.
- Для OpenSSL 3.5.9 и Expat 2.10.0 опубликованы новые замечания низкой важности, исправленные версии которых ещё не вышли. Они будут учтены в следующем обновлении.
