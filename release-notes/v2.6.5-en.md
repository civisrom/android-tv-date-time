## Android TV Time Fixer 2.6.5 — prerelease

**The Android app operates in test mode.**

- Added an ADB terminal with command history, reference examples, and a risk warning.
- Added file transfers and APK and split APK installation on connected devices. Fixed filename handling; saved copies can be deleted from the list.
- Improved wireless pairing and the connection that follows it. Connection and pairing attempts can now be cancelled.
- Progress indicators appear beside their corresponding sections, and connected discovered devices have a bold status label.
- A clear message now explains when the target firmware denies permission to change the NTP server.
- Updated Android screenshots in the Russian README. Automated checks cover 18 emulator configurations and real wireless pairing.
