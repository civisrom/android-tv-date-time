## Android TV Time Fixer 2.6.7

**Приложение для Android работает в тестовом режиме.**

- **Безопасность:** обновлены все необходимые зависимости для устранения критических ошибок и уязвимостей. В версиях для Windows и macOS — OpenSSL 3.5.9 (LTS) и Python 3.12.15, в версии для Linux — последние исправления безопасности Ubuntu 22.04. Также обновлены библиотеки Python, инструменты сборки и библиотеки Android-приложения, включая kadb 2.1.5. Компоненты сборки проверены по базе уязвимостей OSV: известных уязвимостей, затрагивающих программу, не найдено.
- Исправлена обработка потери связи при записи настроек и подключение после сопряжения. Ошибка сопряжения в Android сохраняет действующее соединение.
- Собственный ADB корректно завершается при закрытии Windows-программы. Отмена операций в консоли возвращает меню; остановка сетевой команды в Android сохраняет связь, когда это возможно.
- Проверка сети при запуске больше не ждёт выключенный телевизор. Улучшены профили, восстановление настроек, подсказки подключения и отображение времени. Результаты NTP с одинаковыми IP объединяются.
- Обновлены русская и английская документация, расширены проверки ошибок и регрессий.
