## Android TV Time Fixer 2.6.6

**Приложение для Android работает в тестовом режиме.**

- Добавлены исходные снимки настроек времени и профили устройств с подтверждением, проверкой идентичности и результатов записи. Снимки доступны после перезапуска; ошибки и частичное восстановление показываются явно.
- Добавлены резервные NTP для Android 14+, поддержка IPv6, наблюдение за часами до 10 минут и обезличенный экспорт диагностики. Сохранение настройки, совпадение часов и подтверждение источника времени показываются раздельно.
- Десктопная версия при запуске проверяет сеть, HTTPS, NTP и порт последнего устройства. Подсказки учитывают блокировку интернета и локальных подключений фаерволом, VPN, прокси и изоляцию Wi-Fi. Работа без интернета остаётся доступной.
- Общий каталог расширен на 38 адресов, проверенных настоящими NTP-запросами: теперь 91 альтернативный адрес и 77 стран. Доступность конкретного сервера зависит от сети пользователя.
- В Android исправлены навигация пультом и открытие клавиатуры в полях спаривания на TV, элементы терминала на коротких экранах с крупным шрифтом и устаревшие адреса обнаруженных устройств. Раздел настроек времени перенесён вниз экрана, спаривание — перед часовым поясом; пояснения к новым функциям упрощены. Справочник расширен до 154 примеров в 10 категориях; обновлены криптографические зависимости.
- Исправлены выбор NTP, импорт путей с `~`, очистка служебного ADB и таймауты команд. При переносе данных ADB в Linux и macOS сохраняется список доверенных беспроводных устройств. Расширены проверки отказов сети, прав доступа, отмены, восстановления и интерфейса.
- Добавлена отдельная сборка macOS для Intel; доступны Windows, Linux, macOS Apple Silicon и Intel. В сборках Windows и macOS обновлена среда Python/OpenSSL. Оба README обновлены; добавлены новые русская и английская галереи Android и десктопной консоли.

## Android TV Time Fixer 2.6.6

**The Android app operates in test mode.**

- Added original time-setting snapshots and device profiles with confirmation, identity checks and readback verification. Snapshots survive restarts; failures and partial restorations are reported explicitly.
- Added fallback NTP for Android 14+, IPv6 support, clock monitoring for up to 10 minutes and anonymized diagnostic exports. Stored settings, clock comparison and time-source confirmation are presented separately.
- Desktop startup checks the network, HTTPS, NTP and the last device's port. Guidance covers Internet and LAN firewall restrictions, VPNs, proxies and Wi-Fi isolation. Offline use remains available.
- Added 38 addresses verified with real NTP requests to the shared catalog: 91 alternative addresses and 77 countries. Individual server reachability depends on the user's network.
- Fixed remote-control navigation and keyboard activation in TV pairing fields, terminal controls on short screens with large fonts and stale discovered-device addresses. Moved time settings to the bottom of the screen and pairing above the time zone; simplified explanations of the new features. Expanded the reference to 154 examples in 10 categories and updated cryptographic dependencies.
- Fixed NTP selection, importing paths with `~`, application ADB cleanup and command deadlines. ADB data migration on Linux and macOS preserves the list of trusted wireless devices. Expanded network, permission, cancellation, restoration and interface checks.
- Added a separate macOS Intel build; Windows, Linux, macOS Apple Silicon and Intel builds are available. Updated the Python/OpenSSL runtime in Windows and macOS builds. Updated both READMEs with new Russian and English galleries for Android and the desktop console.
