# Version 2.6.3

**The Android app operates in test mode.**

- Added time zone changes on Android with a collapsible menu, result verification and attempted recovery on failure. NTP settings stay unchanged; operation was confirmed on NVIDIA SHIELD running Android 11.
- Improved Android and desktop NTP selection with five spaced requests, reply validation, availability checks and delay stability assessment. Added seven verified alternative addresses.
- Strengthened address and time-server validation with clear rejection reasons. Large clock differences do not block applying NTP; clock checks show local time, the time zone and UTC.
- Desktop automatic setup now discovers devices via mDNS first: press Enter to confirm a found address. Removed the experimental label; first-time code pairing remains a separate step.
- Fixed Android interface flickering during background connection checks. Added long-press copying of text and addresses with ports.
- Improved country code/name search, scrolling and keyboard handling. Starting a scan collapses lists; selecting a result clears the results and highlights the address field three times.
- Grouped functions into gray panels, emphasized status text and gave primary and secondary buttons different fills. Pairing is collapsible; connection and USB guidance has been expanded.
- Expanded device details with firmware, chip, graphics, storage, display/HDR, audio, decoder declarations and network data. The list starts collapsed and hides unavailable details. Fixed reading compatibility with Android 6.
- Expanded technical details in diagnostics and copied reports. Added a project source code label and GitHub link to Android and desktop versions.
- Updated the Russian and English guides and expanded automated checks on Android 6, 11 and 16.

If your phone cannot discover the TV over USB, try the desktop version. Available information and commands depend on the device firmware.
