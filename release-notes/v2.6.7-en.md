## Android TV Time Fixer 2.6.7

**The Android app operates in test mode.**

- **Security:** updated all necessary dependencies to fix critical bugs and vulnerabilities. The Windows and macOS builds ship OpenSSL 3.5.9 (LTS) and Python 3.12.15, and the Linux build includes the latest Ubuntu 22.04 security updates. Python libraries, build tools and Android app libraries, including kadb 2.1.5, were updated as well. The bundled components were checked against the OSV vulnerability database; no known vulnerabilities affecting the app were found.
- Fixed handling of connection loss while saving settings and connection failures after pairing. Failed pairing on Android preserves the existing connection.
- The application’s ADB process now closes with the Windows app. Cancelling console operations returns to the menu; stopping an Android network command preserves the connection when possible.
- Startup network checks no longer wait for a switched-off TV. Improved profiles, settings restoration, connection guidance and clock displays. NTP results sharing IP addresses are combined.
- Updated Russian and English documentation and expanded failure and regression tests.
