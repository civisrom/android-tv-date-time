## Android TV Time Fixer 2.6.8

**The Android app operates in test mode.**

- **In-app updates:** the Android app has a new “App update” section. It checks GitHub for a new version, downloads the APK, verifies its size, SHA-256 checksum and signature and hands the file to the Android system installer. The user always confirms the installation; on the first update Android asks you to allow the app to install apps. Version 2.6.8 has to be installed manually; later versions can be installed directly from the app.
- **Security:** the Windows and macOS builds ship Python 3.12.16 with `tarfile` and `ssl` fixes, zlib 1.4 and Expat 2.10.0. Updated the certifi 2026.10.23 root certificate bundle (removing emSign root CAs with compromised intermediate keys), pyasn1 0.6.5 (fixes denial-of-service issues in ASN.1 decoding) and other Python libraries. The Linux build includes the latest Ubuntu 22.04 liblzma5 security fix.
- New low-severity advisories were published for OpenSSL 3.5.9 and Expat 2.10.0, with no fixed releases available yet. They will be addressed in the next update.
